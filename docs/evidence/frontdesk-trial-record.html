5. Failures, Gaps & Edge Cases Discovered

Issue Discovered & Resolved: Cold Route Prisma Transaction Timeout (P2028)

During cold Turbopack route compilation of /api/front-office/arrivals, the initial request took ~6.2s to compile. Because the default Prisma interactive transaction timeout was 5,000ms, the initial call failed with error code P2028.

Root Cause: withOrganizationContext() did not specify explicit timeout overrides for cold environments.

Fix Implemented: Updated packages/db/src/context.ts to configure { maxWait: 15_000, timeout: 30_000 } on the interactive transaction options. Cold route compilation now completes smoothly without database connection aborts.

Issue Discovered & Resolved: ICU Parameter Token Casing

Arabic translation message for late arrivals contained an unescaped/mis-cased token in messages.ts.

Fix Implemented: Aligned token casing to {count} across en, tr, and ar dictionaries, verified by unit test suite tests/unit/messages-icu.test.ts.

Documented Architectural Boundaries

  • Walk-in Stays: A walk-in Stay has no associated Reservation; withdrawing a walk-in check-in is refused by design (only check-out can close it).
  • Bed Map Link: The row menu item "Show on bed map" links to /reservations?view=bed-map. It currently lands gracefully on the Reservations tab until the interactive bed map milestone is completed.
