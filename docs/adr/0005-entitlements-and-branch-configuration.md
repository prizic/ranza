# Vary capability through entitlements and supported configuration

Every Dormitory Operator receives the Core Plan, which contains the validated pilot suite and is priced primarily by total Billable Beds: available beds in active Branches, occupied or vacant. Substantial later modules are separate Entitlements. Entitled features may expose supported Operator- or Branch-level configuration modes—for example, Wi-Fi information may be Protected for active members or Public/QR accessible. Prizic governs capabilities and allowed modes through the Control Plane; Operator owners manage safe permitted settings, and Prizic support overrides are audited. Every customer remains on the same product and release line. The post-pilot sequence is Overnight Leave Requests, Student Payments or Full Ledger, Dormitory Accounting, then native mobile applications.
