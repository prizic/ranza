# Ship the pilot as web-first product surfaces

The first pilot will include the complete workflow suite from the product report: nightly attendance, next-day meals, announcements requiring explicit Student acknowledgment, Student balances and partial-payment records without payment processing, and configurable Branch Wi-Fi information. Students and staff will access responsive web applications that may be installed as PWAs; native mobile applications are deferred. The public Storefront is one persuasive page with a contact or demo request, while the internal Prizic Control Plane is limited to Operator and Branch lifecycle, entitlements, supported feature configurations, service health, and audited support actions. This keeps four necessary surfaces viable for one full-time developer without adding self-service commerce or deep platform analytics.
