# Formal-pilot metrics dictionary

The evaluation window is 14 consecutive local calendar days after Attendance and Meals are declared stable.

| Metric                   | Calculation/evidence                                                                                | Success                              |
| ------------------------ | --------------------------------------------------------------------------------------------------- | ------------------------------------ |
| Attendance response rate | before-cutoff submitted responses / eligible active Students, aggregated across Branch nights       | At least 85%                         |
| Management reliance      | days management names Ranza as primary nightly record / applicable days; signed day-14 confirmation | Primary record throughout evaluation |
| Kitchen reliance         | service days kitchen confirms Ranza final count was used / applicable service days                  | Ranza final counts used              |
| Critical data errors     | critical issues opened, resolved, unresolved; link incident references                              | Zero unresolved                      |
| Paid conversion          | signed commercial decision and Subscription/billing-start references                                | Operator agrees to paid Subscription |

Use `docs/pilot/templates/14-day-metrics.csv`. A correction does not erase the original measurement; append a new evidence note. Student-level data is not copied into the metrics sheet.
