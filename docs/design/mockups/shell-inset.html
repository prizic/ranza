Inset shell — proposal

The sidebar and the frame are one surface in the deep emerald (--accent); the page is a single white sheet inset into it. Palette, type, radii and vocabulary are unchanged. Only the arrangement and the frame colour are new. Static mockup, fixture data from visual-reference.md.

One line decides the frame colour: --frame: var(--accent). Set it to hsl(170 60% 10%) for the near-black option.

Desktop · 1440 px

No panel behind the sidebar, no floating page bar. The bar moves inside the sheet, where the back button of ADR 0035 lives on inner pages. Active item: translucent white pill, full-white text; inactive: 74% white (about 7:1 on the emerald).
